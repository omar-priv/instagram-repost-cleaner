# Repost Cleaner — Instagram (1.0.0)

إضافة Chrome / Edge محلية ومفتوحة المصدر لمعاينة Reposts الخاصة بحسابك ومحاولة إزالتها من واجهة Instagram الظاهرة.

## طريقة الاستخدام
1. افتح `chrome://extensions` أو `edge://extensions` وفعّل Developer mode.
2. اضغط Load unpacked واختر مجلد `chrome-extension`.
3. افتح Instagram وسجّل دخولك بنفسك.
4. افتح ملفك الشخصي ← Reposts ← افتح أول Repost بوضع العرض.
5. اضغط فحص؛ الفحص لا يحذف شيئاً ويمر على 200 عنصر كحد أقصى.
6. راجع معاينة المعرّفات، اختر العدد، ثم اضغط ابدأ الإزالة.

## المزايا
- معاينة مسبقة للمنشورات (أول 20 معرّفاً) وسقف 200 عنصر مع تنبيه إذا قد تكون القائمة أطول.
- تحديد عدد المحاولات قبل البدء.
- تحقق من معرّف المنشور وعبارة ملكية Repost وخيار التراجع الصريح قبل الضغط.
- Pause وStop وسجل CSV لمحاولات الواجهة.
- انتظار ثابت لاستقرار الواجهة، لا توقيت عشوائي لتقليد الإنسان.
- توقف عند إشارات التقييد أو طلب التحقق أو الأخطاء؛ لا توجد CAPTCHA bypass أو استكمال تلقائي.

## الخصوصية والحدود
- صلاحية Manifest هي `activeTab` فقط، والمحتوى محصور بـ `https://www.instagram.com/*`.
- لا قراءة لكلمة المرور أو الكوكيز، ولا تخزين للإعدادات أو الطابور، ولا طلبات شبكة من كود الإضافة.
- عداد الإزالة وسجل CSV لمحاولات الواجهة، وليس تأكيداً من خادم Instagram.
- إذا تعذر تحديد منشور أو زر بشكل فريد، تتوقف الأداة بدلاً من التخمين. واجهة Instagram قد تتغير، لذلك لا يوجد ضمان لعمل المحددات على كل حساب.
