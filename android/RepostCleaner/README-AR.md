# Repost Cleaner لنظام Android — 1.0.0

يفتح التطبيق Instagram داخل WebView مستقل، ويحقن محرك التنظيف المحلي من `app/src/main/assets/cleaner.js` على صفحات Instagram HTTPS فقط.

## جلسة تسجيل الدخول
- التطبيق لا يستطيع مشاركة جلسة الدخول الموجودة داخل تطبيق Instagram الرسمي؛ أندرويد يعزل بيانات التطبيقات. سجّل دخولك داخل صفحة Instagram التي يفتحها هذا التطبيق.
- إذا منع Instagram تسجيل الدخول داخل WebView أو طلب فتح التطبيق الرسمي، لا تحاول تجاوز ذلك. استخدم إضافة المتصفح أو احذف Reposts يدوياً.

## التشغيل الآمن
1. افتح التطبيق وسجّل الدخول داخل WebView.
2. افتح ملفك الشخصي ← Reposts ← أول Repost بوضع العرض.
3. افتح لوحة RC العائمة، وافحص حتى 200 عنصر.
4. راجع المعاينة واختر العدد ثم ابدأ. جرّب عدداً صغيراً أولاً.
5. عند أي تحذير أو قيد أو تحقق، تتوقف الأداة.

## الخصوصية والحماية
- إذن Android الوحيد هو `INTERNET` لفتح Instagram. لا يوجد خادم وسيط أو تحليلات أو API خارجي تابع للمشروع.
- يستخدم التطبيق CookieManager لحفظ جلسة WebView الخاصة به فقط؛ لا يشاركها مع تطبيق Instagram الرسمي ولا يقرأ المحرك قيم الكوكيز. زر مسح الجلسة يحذف جلسة هذا التطبيق فقط.
- JavaScript مفعّل لعمل موقع Instagram، لكن لا يوجد `addJavascriptInterface`. الوصول للملفات والمحتوى معطّل، والروابط خارج Instagram تفتح في المتصفح الخارجي. المحتوى المختلط معطّل، وSafe Browsing مفعّل، وWebView يرفض أخطاء الشهادات وفق سلوكه الافتراضي.
- لا توجد متابعة تلقائية بعد تحديث الصفحة أو إعادة فتح التطبيق.
- عداد المحاولات ليس تأكيداً من خادم Instagram. راجع النتيجة يدوياً.

## بناء APK
يُبنى Debug APK عبر GitHub Actions باستخدام JDK 17 وAndroid SDK 35 وGradle 8.9. راجع `BUILD-APK-AR.md` في الجذر.

هذا إصدار تجريبي؛ لم يتم اختبار حذف فعلي على حساب المستخدم، ولا نضمن ثبات محددات واجهة Instagram.
