# Instagram Repost Cleaner — النسخة المدمجة الآمنة

**الإصدار 1.0.0** — إضافة Chrome / Edge + تطبيق Android، مع محرك JavaScript مشترك.

هذه أداة مساعدة محلية للتعامل مع إعادات النشر الخاصة بحسابك من واجهة Instagram الظاهرة. لا تستخدم API غير موثّق، ولا تتصل بخادم وسيط.

## المزايا المدمجة

- فحص مسبق بدون حذف، حتى **200 Repost** في الجولة الواحدة.
- تحذير واضح إذا وصل الفحص إلى 200 وما زال هناك عنصر تالٍ؛ قد تكون القائمة أطول.
- معاينة معرّفات أول 20 منشوراً قبل بدء أي محاولة إزالة.
- اختيار عدد المحاولات المطلوب، من 1 إلى عدد العناصر التي تم فحصها.
- تحقق إضافي قبل كل محاولة: تطابق معرّف المنشور مع ترتيب المعاينة، وظهور ما يدل على أنك أنت أعدت نشره، ووجود زر Repost بحالة مفعّلة.
- البحث عن خيار صريح مثل **Undo repost / Remove repost / التراجع عن إعادة النشر**. لا نضغط زر حذف عام أو زر غير واضح.
- إيقاف مؤقت وإيقاف نهائي.
- سجل محاولات CSV في إضافة المتصفح.
- انتظار ثابت قصير لاستقرار واجهة الصفحة فقط. لا توجد عشوائية لتقليد الإنسان أو إخفاء الأتمتة.
- إيقاف أمان عند إشارات الحظر أو التقييد أو التحقق أو أخطاء الصفحة.

## ما تم استبعاده من النسخة المرفوعة ولماذا

لم ندمج وضع Activity المحدد، ولا الحذف الشامل بضغطة واحدة، ولا التنقل المتتابع غير المرتبط بمعرّف المعاينة، ولا الاستكمال التلقائي بعد تحديث الصفحة، ولا التوقيت العشوائي. بعض هذه المسارات كان يختار زر الحذف على مستوى الصفحة بدلاً من ربطه بالعنصر المحدد، وبعضها يستطيع إعلان نجاح غير متحقق منه أو متابعة الحذف بعد إعادة التحميل. إبقاؤها كان سيزيد احتمال حذف عنصر غير مقصود أو مواصلة العمل بعد انقطاع.

## التثبيت — Chrome / Edge

1. فك ضغط المشروع.
2. افتح `chrome://extensions` في Chrome أو `edge://extensions` في Edge.
3. فعّل **Developer mode**.
4. اضغط **Load unpacked** واختر مجلد `chrome-extension`.
5. افتح `https://www.instagram.com/` وسجّل الدخول داخل Instagram نفسه.
6. افتح ملفك الشخصي ثم تبويب Reposts، وافتح أول منشور بوضع العرض.
7. افتح إضافة Repost Cleaner، واضغط الفحص. لن تحذف الأداة شيئاً أثناء الفحص.
8. راجع المعاينة، اختر العدد، ثم اضغط ابدأ الإزالة.

## Android

1. ثبّت APK التجريبي المبني من GitHub Actions.
2. افتح التطبيق وسجّل الدخول **داخل صفحة Instagram التي يفتحها التطبيق**.
3. جلسة WebView مستقلة عن تطبيق Instagram الرسمي؛ أندرويد لا يشارك جلسة التطبيقين تلقائياً.
4. افتح ملفك الشخصي → Reposts → أول منشور، ثم استخدم لوحة RC العائمة.

زر CSV متاح في إضافة المتصفح فقط؛ لم نعرضه في Android WebView لأن تنزيل Blob لا يعمل بشكل موثوق من دون إضافة مسار تنزيل أصلي وصلاحية إضافية.

## ضوابط السلامة والخصوصية

- لا تدخل كلمة المرور في الأداة ولا تخزنها.
- إضافة Chrome لا تطلب صلاحية قراءة الكوكيز أو التخزين أو كل المواقع؛ صلاحيتها `activeTab` فقط، ومطابقتها محصورة في نطاق Instagram HTTPS.
- كود الإضافة لا يقرأ `document.cookie` ولا يرسل طلبات `fetch` أو XHR أو Beacon ولا يرسل بيانات لخادم خارجي.
- تطبيق Android يستخدم CookieManager داخلياً كي يحافظ WebView على **جلسته الخاصة**؛ لا يقرأ المحرك قيم الكوكيز ولا يشاركها مع إضافة المتصفح أو تطبيق Instagram الرسمي.
- لا توجد CAPTCHA bypass أو تجاوز تحقق أو محاولات للتحايل على حدود Instagram.
- عند ظهور Action Block أو Try Again Later أو Checkpoint أو نشاط غير معتاد أو مشكلة شهادة/شبكة، تتوقف العملية. افحص الحساب يدوياً ولا تعاود التشغيل مباشرة.
- لا توجد متابعة تلقائية بعد تحديث الصفحة أو إغلاق التطبيق. عند الانقطاع، أعد فتح العنصر الأول وافحص من جديد.
- عدّاد الإزالة وسجل CSV يصفان **محاولات تفاعل واجهة المستخدم** فقط، ولا يثبتان أن خادم Instagram أكّد حذف كل عنصر. راجع النتيجة يدوياً.
- واجهة Instagram تتغير؛ إذا لم يستطع المحرك تحديد عنصر أو زر بشكل فريد، يجب أن يتوقف بدلاً من التخمين.

## الملفات

- `chrome-extension/` — إضافة Chrome / Edge.
- `android/RepostCleaner/` — مشروع Android.
- `scripts/check-source.sh` — فحوص JavaScript والبيانات والصلاحيات.
- `.github/workflows/build-android.yml` — بناء APK تلقائياً على GitHub Actions.
- `REVIEW-2.1.0-AR.md` — تقرير مراجعة النسخة التي رفعها المستخدم والقرارات التي اتخذت.

## فحوصات المصدر

شغّل `sh scripts/check-source.sh` من المجلد الرئيسي. هذا يفحص صياغة JavaScript وبيانات Manifest وبعض الأنماط الحساسة؛ وهو فحص ثابت للمصدر، وليس اختباراً على حساب Instagram حي.

**حدود الاختبار:** نجاح البناء لا يثبت أن كل محددات Instagram ستعمل في كل حساب أو لغة أو تصميم. لم يتم تنفيذ حذف فعلي على حساب المستخدم. جرّب أولاً بعدد صغير وتحقق يدوياً.
